## Category
Productivity

## Description
PageVera saves the page you're reading as a clean file, in one click, with no print dialog.

Choose PDF, PNG or Markdown from the popup, from the keyboard shortcut (Alt+Shift+P, or ⌥⇧P on a Mac) or from the right-click menu.

What it does
- Leaves out the top navigation, sidebars, footer, popups, cookie banners and chat widgets, and lets the content use the freed space.
- Lets you click any element on the page to leave it out first.
- Scrolls to the end before saving, so images that load as you scroll and infinite feeds are included.
- PDF: real text you can search and copy, working links, images at their original resolution, and normal paper pages with images and slides kept whole at page breaks. One long page is also available.
- PNG: one picture of the whole page.
- Markdown: headings, lists, tables, code blocks and links in a plain .md file. Images become links.
- Prints every slide of a carousel or slideshow, and works inside embedded course players and document viewers.
- Names the file after the page, or after the lesson inside a course player.

Privacy
PageVera has no server and collects nothing. It reads a page only when you save it, and the file is made on your computer. It asks for no access to websites in advance.

Good to know
- Chrome shows a "started debugging" bar for a few seconds while a file is being made. It goes away when the save finishes.
- Pages drawn on a canvas, such as Google Docs and Figma, come out as images. Feeds that unload items as you scroll, such as X and Gmail, only include what is on screen.
- Chrome blocks extensions on its own pages and on the Chrome Web Store.

Source code and the full list of limitations: https://github.com/muhamoussa7/pagevera

## Single purpose
Save the current web page as a PDF, PNG or Markdown file.

## Permission justifications

debugger
PageVera calls Chrome's own Page.printToPDF and Page.captureScreenshot commands to make the file, which is the only way for an extension to print a page without the print dialog and keep text as real text. It is attached only to the tab the user saves, only after the user clicks save, and it is detached when the save ends. It is not used to read network traffic, cookies or form data.

scripting
Injects the script that prepares the page for saving (hides navigation and popups, loads lazy images) and the click-to-remove picker into the tab the user saved. Every change is undone when the save finishes.

activeTab
Gives access to the current tab only after the user clicks the toolbar button, uses the shortcut or picks the context menu item. No website access is requested in advance.

downloads
Saves the finished file through Chrome's download manager, with a file name based on the page title, and optionally into a subfolder of the Downloads folder.

storage
Stores the user's options (what to remove, format, layout) and the state of a save in progress.

offscreen
Chrome's service worker can't create Blob URLs. An offscreen document assembles the file bytes into a Blob so the download manager can save it.

contextMenus
Adds "Save page with PageVera" and "Save page with PageVera, picking what to remove…" to the right-click menu.
